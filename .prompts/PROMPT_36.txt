### 2. E5 TimescaleDB — lessons

Target **9 lessons**:

1. `timescale-what-it-is` — hypertables as automated range
   partitioning + chunk management; what Timescale does that
   core Postgres does not do as easily.
2. `creating-a-hypertable` — `create_hypertable`, chunk time
   intervals, space partitioning.
3. `continuous-aggregates` — what they are, refresh policies,
   when they beat plain matviews + scheduled refresh.
4. `compression-and-downsampling` — compression policies,
   tradeoffs, how it interacts with updates.
5. `retention-policies` — declarative retention.
6. `query-patterns-that-win` — where Timescale's planner wins vs
   loses.
7. `operational-posture` — backups, replication, upgrades; AGPL
   vs commercial Timescale; managed-service choices (Timescale
   Cloud, AWS TSDB managed offering landscape).
8. `when-core-partitioning-is-enough` — the explicit "not yet"
   framework — partition counts, query latency, operational
   comfort, analytics maturity.
9. `migrating-to-timescale` — how to move an existing partitioned
   core table into a hypertable; how to revert.

### 3. E6 postgres_fdw deep — lessons

Target **8 lessons**:

1. `predicate-pushdown-fundamentals` — which predicates push,
   which do not; types and operators pushable.
2. `join-pushdown-and-aggregate-pushdown` — Postgres 14+ joint
   and aggregate pushdown; verifying via EXPLAIN VERBOSE.
3. `async-append-for-fdw` — asynchronous execution for multi-FDW
   queries.
4. `foreign-table-statistics` — `ANALYZE` over FDW; the cost;
   implications for planner.
5. `authentication-patterns` — `CREATE USER MAPPING`; secrets
   management; SSL considerations.
6. `reliability-modes` — what happens when the foreign server
   is slow or unavailable; timeouts; circuit-breaker-style
   patterns at the application layer.
7. `pushdown-trips-and-rewrites` — wrapping expressions in
   pushdown-friendly forms; avoiding non-pushable functions.
8. `from-fdw-to-logical-replication` — progressing from federation
   to consolidation; the migration path into a single cluster or
   to a proper ownership split.

### 4. Exercises

Per lesson: 2A + 2B + 2C + 2D. ~136 exercises.

Critical drills:

- Timescale Level C: convert a phase-09 partitioned events
  table's analysis workload into a hypertable + continuous
  aggregate; compare query times.
- Timescale Level D: a compression policy that silently prevents
  updates to historical rows that operations actually need to
  update; learner diagnoses and proposes a different retention
  posture.
- FDW Level C: configure predicate pushdown to a foreign table and
  demonstrate EXPLAIN VERBOSE showing the pushdown.
- FDW Level D: an aggregate query that does not push down due to
  a non-pushable function; learner rewrites.
- FDW Level D: a reliability drill — foreign server is made slow
  (via a `pg_sleep` trigger or similar); learner diagnoses via
  pg_stat_activity and proposes a timeout/circuit-breaker
  pattern at the app layer.
