# Phase 4 Lessons

Phase 4 teaches PostgreSQL-native modeling choices: timestamps, UUIDs, JSONB,
arrays, ranges, multiranges, generated columns, and exclusion constraints. The
bar is choosing a type because it makes the model clearer or more enforceable,
not because the feature is available.
