# postgres-foundations

`postgres-foundations` is a public-facing PostgreSQL training lab, assessment
system, design studio, and planning engine. It teaches PostgreSQL from beginner
through practical competence while helping users reason about architecture,
features, topology patterns, and extensions from real workload signals.

Start with [doctrine](docs/doctrine.md) for the project's operating principles
and [architecture](docs/architecture.md) for the three-subsystem overview.
