# When a Materialized View Helps Level D1

Diagnose a stale materialized view that was treated as the source of truth; recommend a refresh policy or a regular view.

Success means the answer is correct for the Phase 5 seed data, uses only Phase 5 expressive-querying concepts and earlier concepts, and avoids turning the task into indexing, concurrency, partitioning, full-text search, or RLS work.
