# When Partial Indexes Win Level D1

## Scenario

The operations dashboard reads rare pending orders ordered by recent placement time.

## Task

Critique the proposed fix. Name the broken assumption, capture or describe the plan evidence, and defend the pending-order dashboard should keep or reject the partial index. Your answer must include the artifact: a partial index whose predicate is provably implied by the query.

## Required Artifact

Submit the relevant SQL or critique notes plus the before/after plan observations. Name the read benefit, write or storage cost, and the condition that would make you remove or defer the index.
