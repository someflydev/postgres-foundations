# The Maintenance Win Level A1

## Scenario

An orders table has overlapping customer and status indexes from several tuning passes.

## Task

Identify the predicate, expression, or operator that drives the plan. Record the baseline evidence and explain what unused or redundant index maintenance cost using size and scan evidence would prove before deciding which index should be kept, replaced, or dropped concurrently.

## Required Artifact

Submit the relevant SQL or critique notes plus the before/after plan observations. Name the read benefit, write or storage cost, and the condition that would make you remove or defer the index.
