# Structured Review Output

Return Markdown with these sections:

## Scores

Table with columns: dimension, score, justification.

## Feedback

Numbered list of specific, actionable items. Each item must cite a learner
artifact fragment or absence.

## Forbidden Concepts

List any concepts used before introduction. Say `None observed` when absent.

## Questions

Two oral-defense questions that test whether the learner can explain the work.
