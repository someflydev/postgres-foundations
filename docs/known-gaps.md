# Known Gaps

This file records honest release gaps discovered during the PROMPT_50 audit.

## Level D Exercise Coverage

Owner: Curriculum maintainer.

The phase 0-10 lesson corpus meets the minimum active lesson count per phase,
but the "one Level D exercise per lesson cluster" audit is not yet clean for
every cluster. Existing exercise paths are organized around lesson slugs rather
than the full lesson cluster hierarchy, so the next curriculum pass should
define the canonical cluster key and fill any missing Level D coverage against
that definition.

## Quickstart Human Freshness
