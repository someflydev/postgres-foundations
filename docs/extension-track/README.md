# Extension Track

The extension track teaches PostgreSQL extensions from workload evidence, not from novelty. Each module asks what core PostgreSQL already provides, what capability is missing, what the extension costs operationally, and how portable the decision is across managed services.

Current authored modules:

- E1 `pg_stat_statements` deep workload observation.
- E2 `pg_trgm` typo-tolerant matching and trigram indexes.

Future modules listed in `curriculum/extensions/map.json` cover PostGIS,
pgvector, TimescaleDB, postgres_fdw, pg_cron, ltree, pg_partman, and
PgBouncer. Those entries are anchors only until their prompts author lesson
content.
