# Administration Track

The administration track starts after phase 10. It assumes the learner can
already reason about schema design, transactions, indexing, RLS, replication,
and FDW. The admin modules turn that knowledge into daily operational practice.

Modules A1 and A2 are authored in `lessons/admin/` and `exercises/admin/`.
A3 through A6 are present in `curriculum/admin/map.json` as the remaining
administration anchors.

- A1: roles and privileges.
- A2: schemas and databases.
- A3: authentication and pooling.
- A4: backup, restore, vacuum, and upgrades.
- A5: monitoring and performance operations.
- A6: replication and high availability.
